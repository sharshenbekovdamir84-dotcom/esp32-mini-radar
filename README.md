# esp32-mini-radar
Мини-радар на ESP32 для обнаружения объектов и измерения расстояния
## Состав команды
- Шаршенбеков Дамир Эмилбекович
- разработчик проекта.
## Идея проекта
Мини-радар на базе ESP32 предназначен для обнаружения объектов и измерения расстояния до них.
Ультразвуковой датчик HC-SR04 измеряет расстояние до объекта, а сервопривод SG92R поворачивает датчик, обеспечивая сканирование пространства.
Результаты сканирования отображаются на экране радара. При приближении объекта зуммер подаёт звуковой сигнал.
## Цель проекта
Создать компактный радар для обнаружения объектов с использованием микроконтроллера ESP32, ультразвукового датчика и сервопривода.
